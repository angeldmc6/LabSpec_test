Publicar en GitHub

¿Cómo funciona?
Al hacer clic en "Publicar", el panel sube el archivo contenido.json directamente a tu repositorio de GitHub. GitHub Pages lo detecta y actualiza el sitio en segundos — sin descargar ni subir archivos manualmente.

Configuración (solo una vez):
1. Ve a github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Crea un token con permiso Contents: Read and write solo para tu repositorio
3. Pega el token y los datos del repositorio abajo. Se guardan en tu navegador.
Sin configurar

Se guarda solo en este navegador (localStorage). Nunca se envía a ningún servidor externo.
